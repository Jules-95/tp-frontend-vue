# Mon appli — TP Vue 3

Gabarit du TP : Vue 3, TypeScript, Vue Router, Pinia, Naive UI, Tailwind CSS et Vitest, déjà installés.

1. Lire `SUJET.md` (dans VS Code : clic droit → Ouvrir l'aperçu).
2. `npm install`, puis `npm run dev`. Node 22.22 ou plus (ou 24.15 et plus).
3. Remplir `EXIGENCES.md` au fil de l'eau.
